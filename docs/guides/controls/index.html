Getting started

Controls at a Glance

What every button does now. The patch gives R, L, START and SELECT new jobs in the field, the Bag and battle.

Last updated October 2, 2026

All of this works on existing saves. The full description of each feature, with screenshots, is on the Features page.

In the field

ButtonWhat happens
ROpens the DexNav: every wild Pokémon on the map you are standing on. A on a species starts a search, B closes.
LOffers a Repel: “Use the Max Repel?”, falling back to Super Repel, then Repel. Silent while one is active or when you carry none.
SELECTOpens the key-item ring around you: press ▲ ▶ ▼ ◀ to use the item in that box, A for the PC, B or SELECT to close.
B heldRun, or walk if Auto Run is on. While surfing: go twice as fast (or slow down, with Auto Run on).
STARTThe usual menu, with a DexNav entry. R inside the menu opens the Quest Log.

In the Bag

ButtonWhat happens
STARTSorts the current pocket. Each press cycles type → name → amount; the description box says which.
SELECTMoves an item (unchanged from the hack).
◀ ▶Switch pockets. The hack uses the D-pad here, not L and R.
RegisterIn the Key Items pocket it works on up to four items; each one takes a place on the SELECT ring.

In battle

WhereButtonWhat happens
Wild battle, action menuR tapThrows the first ball in your Poké Balls pocket without opening the Bag.
Wild battle, action menuR holdShows the ball and how many you have. While holding, ◀ ▶ picks another ball.
Move list—The highlighted move’s damage multiplier against the target shows in front of the PP count.

Quick throw is off in trainer, Safari, double, link and Battle Frontier battles, when you have no balls, and when both party and PC are full.

In menus

WhereHowWhat happens
Party menuMovesOpens the Move Relearner for that Pokémon. No Heart Scale needed.
Party menu, in a dark caveFlashLights the cave if you own HM05 and the badge, even if nobody knows Flash.
START → OptionText SpeedA fourth setting, Instant: each page of text appears at once.
START → OptionAuto RunRun without holding B. Replaces Button Mode.
Key ItemsJournalTells you the next story objective and opens the Quest Log.
Key ItemsSinnoh MapA map of Sinnoh (or Hisui) with a free cursor; A flies to a town you have visited.
BagExp. ShareUse it to switch the Exp. Share off and on.

Field moves without the Pokémon

Own the HM and the badge, and Cut, Strength, Rock Smash, Surf, Waterfall and Dive work straight from the tree, boulder, rock or water, even when nobody in your party can learn the move. Your first Pokémon that is not an Egg does it. A Pokémon that can learn the move is still picked first, and Rock Climb is unchanged.
