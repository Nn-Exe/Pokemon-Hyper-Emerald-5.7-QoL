Help

FAQ & known issues

Patch problems, save problems, and the hack's own quirks. Check here before assuming your ROM is broken.

Patching

"this is not the expected original ROM"

Your file is not the "bugfix 2" build of v5.7. Check the SHA-1 against f785bed9d9e82e8da13ea4a5ad747e3ea4ec7ba9 (see Install & play). Vanilla Emerald is 16 MB; the hack is 32 MB. The older community English ROM will also be refused: the patch already contains the full translation, so it has to start from the untouched Chinese ROM.

Can I apply this on top of another patch or cheat-modified ROM?

No. The patcher compares every byte it changes with what it expects, so any other modification makes it stop. Apply to a clean ROM and add cheats as emulator codes instead.

Does it need the translation-only build first?

No. The release patch goes from the Chinese ROM straight to the final build in one step.

Saves

My save is gone after switching to the new ROM

Emulators match the .sav by file name. Rename either the ROM or the save so the base names match. The save data itself is compatible in both directions.

Can I use save states from the old ROM?

No. Save states capture the whole ROM image and memory, so they only work with the exact ROM they were made on. Save in-game, switch ROMs, then load the battery save.

Will future patch versions break my save?

The QoL features keep their state in bytes the game never used and the save format is untouched, so updates are designed to be save-compatible. Keep a backup of the .sav anyway.

The hack's own known issues

These come from the hack, not from the patch, and were reported by players of v5.5–v5.7. Workarounds where known:

ProblemWhat to do
Softlock or freeze with the sound mode set to StereoSet sound to Mono in the in-game Options menu. Reported for several versions.
No experience after the Elite Four in some savesLinked to the trainer-level / obedience system; check that your trainer level is high enough for your Pokémon's level and keep progressing the post-game story. Save often.
Crash when catching certain Pokémon with a Master BallUse another ball on legendaries where possible, or save before throwing.
Crash in the post-game Xerneas encounter (older versions)Fixed in the "bugfix" builds of v5.7. Make sure your base ROM is bugfix 2.
Shop purchase soft-resets the gameOnly happens for shops that the hack's custom mart code does not know; the retail shops are fine. This is why the patch does not add a Rare Candy shop.
The bag freezes when the cursor lands on one itemPress SELECT to skip over that item, then B to leave the bag.
Save disappears after the League (PC emulators)Set the emulator's save type to Flash 128K; the hack needs the full 128 KB save.
Evolution by stone does not teach the new form's moveUse the party menu's Moves option (the patch's relearner) to pick it up.
Game freezes in the Volo / Arceus cutsceneThis was a bug in the older community translation (text written into memory the game still used). The current patch fixes it.

Text

I still see a few Chinese lines

About 50 strings are intentionally left in Chinese: link-battle and Trainer Card messages that end in a page-break control (rewriting those can hang the text engine), a few short name-table entries without context, and text baked into images such as the title logo. If you see Chinese dialogue during normal play, report it with a screenshot on the GitHub issues page.

A stat-boost message from an X item is not coloured

The hack draws that message inside the bag window with its own routine that ignores colour codes. Stat changes from moves and abilities are coloured.

Features

R does nothing in battle

Quick throw only works in wild single battles at the action menu, with at least one ball in the Poké Balls pocket and room in the party or PC. It is disabled in trainer, Safari, double, link and Battle Frontier battles.

R does not toggle running

You need the Running Shoes, and the map must allow running (as in vanilla, you cannot run inside most buildings).

L does nothing

Either a repel is already active or you carry none. The hack's own "use another?" prompt still appears when a repel wears off.

The relearner returns me to the overworld

That is expected; the game's relearner exits to the field. Open the party menu again to continue.

General

Is the hack complete?

Yes. v5.7 is a finished release with Hoenn, Sinnoh and the post-game. The English patch has been played through the areas its tests cover, not all forty-plus hours, so odd text is still possible in deep post-game screens.

Where do I get the ROM?

The guide and the repository do not distribute ROMs. Get the hack from its original release thread and patch it yourself.
