Hyper Emerald FAQ

Straight answers about patching Hyper Emerald v5.7, saves, the new controls, and the hack’s own known issues. Check here before assuming your ROM is broken.

Last updated October 1, 2026

Getting started

What is Hyper Emerald?

Hyper Emerald: Lost Artifacts (究极绿宝石) is a Chinese ROM hack of Pokémon Emerald by Destvol, Satochu, Popy, Potato, Hurricane, Feiyixiang and others. On top of the Hoenn story it adds the whole Sinnoh region as post-game, Mega Evolution, Z-Moves and Dynamax, every species through Sword and Shield, a trainer-level system, over a hundred side quests and a hard mode.

Is the hack complete?

Yes. v5.7 is a finished release with Hoenn, Sinnoh and the post-game. The English patch has been played through the areas its tests cover, not all forty-plus hours, so odd text is still possible in deep post-game screens.

What do I need to play?

The “bugfix 2” build of Hyper Emerald: Lost Artifacts v5.7 (the Chinese hack itself, 32 MB), the patch file from the repository, Python 3 to apply it, and a GBA emulator. Install & Play walks through it.

Where do I get the ROM?

This site and the repository do not distribute ROMs. Get the hack from its original release thread and patch it yourself.

Which emulator is recommended?

mGBA. Everything in the patch was tested on it. RetroArch with the mGBA core, standalone mGBA on Android and mGBA 0.10.x on a homebrew Switch all run the hack.

How do I know which version I am on?

Open START → Option. The title reads “Ultra Emerald v5.7 +QoL1.7” followed by your difficulty when you are on the current build.

ROM patching

The patcher says “this is not the expected original ROM”

Your file is not the “bugfix 2” build of v5.7. Check its SHA-1 against f785bed9d9e82e8da13ea4a5ad747e3ea4ec7ba9 (see Install & Play). Vanilla Emerald is 16 MB; the hack is 32 MB. The older community English ROM is also refused: the patch already contains the full translation, so it has to start from the untouched Chinese ROM.

Can I apply this on top of another patch or a cheat-modified ROM?

No. The patcher compares every byte it changes with what it expects, so any other modification makes it stop. Apply to a clean ROM and add cheats as emulator codes instead.

Does it need the translation-only build first?

No. The release patch goes from the Chinese ROM straight to the final build in one step.

The game crashes right after New Game, in the mountain cutscene

That was a bug in this patch’s own releases before 2026-09-14: a translation pass had overwritten a few of the hack’s movement scripts (the cutscene where the villains line up on the mountain, the Slateport Contest Hall reception and six later scenes). Re-apply the current patch to a clean Chinese ROM; your .sav keeps working.

Saves

My save is gone after switching to the new ROM

Emulators match the .sav by file name. Rename either the ROM or the save so the base names match. The save data itself is compatible in both directions.

Can I use save states from the old ROM?

No. Save states capture the whole ROM image and memory, so they only work with the exact ROM they were made on. Save in-game, switch ROMs, then load the battery save.

My Items pocket looked empty after updating

That happened on v1.6 when the game carried on from an emulator save state made on an older version: the items had not yet been moved into the new 200-slot pocket. Nothing was lost, and the current build moves them in that case too.

Will future patch versions break my save?

Updates are designed to be save-compatible: the features keep their state in bytes the game never used. Keep a backup of the .sav anyway; it is a 128 KB file.

My save disappears after the League

Set the emulator’s save type to Flash 128K. The hack needs the full 128 KB save.

Controls and features

R no longer toggles running

Auto Run moved to START → Option (it replaces Button Mode); turn it on there once. R in the field now opens the DexNav. Every button is listed here.

R does nothing in battle

Quick throw only works in wild single battles at the action menu, with at least one ball in the Poké Balls pocket and room in the party or PC. It is off in trainer, Safari, double, link and Battle Frontier battles.

L does nothing

Either a repel is already active or you carry none. The hack’s own “use another?” prompt still appears when a repel wears off.

The PC on the SELECT ring is crossed out in red

You are in Rainbow Castle, Allearth Forest, Giant Chasm, Spear Pillar, the Distortion World or Mt. Silver. The ring’s PC is switched off there to keep those dungeons a challenge. A PC that stands in the area still works, and so do your registered key items.

A Pokémon in the DexNav is a black shadow named “?????”

You have not seen that species yet, so it cannot be searched. Meet it once in any battle and it shows up normally.

The relearner returns me to the field

That is expected; the game’s Move Relearner exits to the field. Open the party menu again to continue.

Where did the Rare Candy NPC in Petalburg’s Poké Mart go?

He was removed in v1.7: 999 Rare Candies for a single “yes” made levelling pointless. Candies you already received stay in the Bag.

A stat-boost message from an X item is not coloured

The hack draws that message inside the Bag window with its own routine, which ignores colour codes. Stat changes from moves and abilities are coloured.

The hack’s own known issues

The game freezes or softlocks with the sound set to Stereo

Set sound to Mono in the in-game Option menu. Reported for several versions of the hack.

My Pokémon stopped gaining experience

In every mode except Easy, Pokémon stop gaining experience at the current level cap, which rises with badges and league wins. After the Elite Four, keep progressing the post-game story. See level caps and obedience.

The game crashes when I catch certain Pokémon with a Master Ball

Use another ball on legendaries where possible, or save before throwing.

The Bag freezes when the cursor lands on one item

Press SELECT to skip over that item, then B to leave the Bag.

Evolving with a stone did not teach the new form’s move

Use the party menu’s Moves option (the patch’s relearner) to pick it up.

Sprites look wrong after a warp

An NPC in the game explains it: “If this happens, just switch screens and it will go back to normal.”

The post-game Xerneas encounter crashes

Fixed in the “bugfix” builds of v5.7. Make sure your base ROM is bugfix 2.

Text and reporting

I still see a few Chinese lines

About 50 strings are intentionally left in Chinese: link-battle and Trainer Card messages that end in a page-break control (rewriting those can hang the text engine), a few short name-table entries without context, and text baked into images such as the title logo. If you see Chinese dialogue during normal play, report it with a screenshot on the GitHub issues page.

How do I report a bug?

Open an issue on the repository with a screenshot, what you were doing, your emulator, and the version from the Option screen. A copy of your .sav makes a crash much easier to reproduce.

Can I contribute?

Yes. Every feature is a standalone patcher with its own test, and pull requests are welcome on GitHub. Corrections to this guide are welcome too.
