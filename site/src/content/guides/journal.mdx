The **Journal** is a key item the patch hands you automatically. Use it from the Bag (or register it to SELECT)
and its Quest Log lists these objectives by chapter, with the titles below, and marks the first one you have not
done. From the Start menu, <Key>R</Key> opens it too.

<Callout type="plain" title="How the Journal picks one">
  It finds the last objective you finished that can only happen in order, then shows the first unfinished one after
  it. Objectives tagged <Tag type="warn">any order</Tag> can be done early or skipped for a while; doing one early
  never makes the Journal jump ahead. For groups (badges, Tapu trials, Plates) it also shows your progress and what
  is still missing.
</Callout>
