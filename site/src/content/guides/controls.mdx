[Features](/features/) page.

## In the field

| Button | What happens |
| --- | --- |
| <Key>R</Key> | Opens the **DexNav**: every wild Pokémon on the map you are standing on. <Key>A</Key> on a species starts a search, <Key>B</Key> closes. |
| <Key>L</Key> | Offers a Repel: "Use the Max Repel?", falling back to Super Repel, then Repel. Silent while one is active or when you carry none. |
| <Key>SELECT</Key> | Opens the **key-item ring** around you: press <Key>▲</Key> <Key>▶</Key> <Key>▼</Key> <Key>◀</Key> to use the item in that box, <Key>A</Key> for the **PC**, <Key>B</Key> or <Key>SELECT</Key> to close. |
| <Key>B</Key> held | Run, or walk if **Auto Run** is on. While surfing: go twice as fast (or slow down, with Auto Run on). |
| <Key>START</Key> | The usual menu, with a **DexNav** entry. <Key>R</Key> inside the menu opens the Quest Log. |

## In the Bag

| Button | What happens |
| --- | --- |
| <Key>START</Key> | Sorts the current pocket. Each press cycles **type → name → amount**; the description box says which. |
| <Key>SELECT</Key> | Moves an item (unchanged from the hack). |
| <Key>◀</Key> <Key>▶</Key> | Switch pockets. The hack uses the D-pad here, not L and R. |
| *Register* | In the Key Items pocket it works on up to **four** items; each one takes a place on the SELECT ring. |

## In battle

| Where | Button | What happens |
| --- | --- | --- |
| Wild battle, action menu | <Key>R</Key> tap | Throws the first ball in your Poké Balls pocket without opening the Bag. |
| Wild battle, action menu | <Key>R</Key> hold | Shows the ball and how many you have. While holding, <Key>◀</Key> <Key>▶</Key> picks another ball. |
| Move list | — | The highlighted move's damage multiplier against the target shows in front of the PP count. |
| Move list | <Key>L</Key> hold | A panel slides in with the highlighted move's exact Power and Accuracy, Physical / Special / Status, contact, Priority and the chance of its extra effect. Let go and it slides away. |

Quick throw is off in trainer, Safari, double, link and Battle Frontier battles, when you have no balls, and when
both party and PC are full.

## In menus

| Where | How | What happens |
| --- | --- | --- |
| Party menu | *Moves* | Opens the Move Relearner for that Pokémon. No Heart Scale needed. |
| Party menu, in a dark cave | *Flash* | Lights the cave if you own HM05 and the badge, even if nobody knows Flash. |
| START → Option | *Text Speed* | A fourth setting, **Instant**: each page of text appears at once. |
| START → Option | *Auto Run* | Run without holding <Key>B</Key>. Replaces Button Mode. |
| START → Option | *Exp. Gain* | **Off** stops every Pokémon gaining experience, for level caps and challenge runs. This is the row that used to be labelled Sound. |
| START → Option | *Day/Night* | **Off** keeps the daytime colours at any hour. The clock keeps running. |
| Naming screen | <Key>SELECT</Key> | Switches between the **UPPER**, **lower** and **others** pages of the English keyboard. |
| Key Items | *Journal* | Tells you the next story objective and opens the Quest Log. |
| Key Items | *Sinnoh Map* | A map of Sinnoh (or Hisui) with a free cursor; <Key>A</Key> flies to a town you have visited. |
| Bag | *Exp. Share* | Use it to switch the Exp. Share off and on. |

## Field moves without the Pokémon

Own the HM and the badge, and Cut, Strength, Rock Smash, Surf, Waterfall and Dive work straight from the tree,
boulder, rock or water, even when nobody in your party can learn the move. Your first Pokémon that is not an Egg
does it. A Pokémon that can learn the move is still picked first, and Rock Climb is unchanged.
